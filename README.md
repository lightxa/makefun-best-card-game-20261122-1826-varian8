The Midnight Post is a trick-taking courier card game across a moonlit city. You are a night courier racing the rival courier Rook to deliver letters before midnight: pick delivery contracts, pay stamp costs for the cards you play, spend stamps on costed tools (Express Seals and Shortcuts), and watch the midnight deadline track tick down. Four districts, each told apart by colour and shape, set the table: Lantern Row, Canal Steps, Rooftop Lanes and Moon Market, the trump suit. Rook shows his intent on screen, so his choices can be read and countered. First to 60 letters wins the night; lose all three hearts and the post is lost.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

Then open out/game/index.html in desktop Chrome, or serve the out directory with any static HTTP server. No build step, no network.
